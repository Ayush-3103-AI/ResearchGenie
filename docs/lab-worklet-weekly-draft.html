Worklet titleResearchGenie: turn a research question into an evidence-grounded, citation-verified paper draft, running on a local model by default
KPI & expectationsA complete four-stage run (Discovery → Writing → Verification → QA) on a local 9B model (qwen3.5:9b). Every reference is classified verified / invalid / unverifiable. A deterministic QA score from 0 to 5. A failed run can be diagnosed and resumed, not restarted.
Measured: QA overall 3.5–4.2 / 5 across real runs; best draft 3,421 / 4,000 words; a full live run takes about 15 min. Test suite: 516 passed, 3 skipped (branch r3/integration, 20 Oct); CI runs on every push.
