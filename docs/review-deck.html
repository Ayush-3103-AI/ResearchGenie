ResearchGenie

It turns a research question into an evidence-grounded, citation-verified paper draft. A team of agents does the work on a 9B model on a laptop, and a human makes the decisions.

The problem

A chatbot writes fluent papers with made-up references

It invents citationsIt produces references that look plausible and are not real, and nothing checks them.
Nothing is traceableYou cannot see which paper a claim came from.
A failure costs everythingA 15-minute run that fails at minute 14 starts again from zero.
It needs the cloudStudents pay per token, and their data leaves the machine.
Architecture

Four agents in a pipeline, and three that work around it

Novelty

What is new here

Never repairs a citationEach reference is verified, invalid or unverifiable. Code checks it; the model does not.
Self-healing, not self-guessingThe Doctor quotes its evidence, asks first, and resumes from the failed stage.
An agent that improves the productThe Dev Agent shipped APA 7: red test first, guard tests, a human applies the diff.
Memory that respects safetySeeded past papers still pass the relevance gate.
Gaps need agreementA research gap counts only when several independent papers raise it.
One next actionA deterministic brief tells the student exactly where their judgement is needed.

Honest limits

What we have not solved

Fixed order
The order of the stages is fixed in code, on purpose, for auditability. The model adapts inside each stage.
9B model
Long sections sometimes fall short of the target length. Gemini is one setting away.
No semantic search
The library uses full-text search, not embeddings.
No login
The hosted demo is for the review only, and access to it is restricted.
